# Laram Skin

Static Persian RTL website for Laram Skin.

Website files are in the repository root. No build step is required.

This repository is a snapshot of the approved website. GitHub Pages and custom-domain publishing are not configured or enabled by this import.

Includes generated brand imagery, slider frame sheets, and supplied certificate images. Certificate content has not been independently authenticated. Do not represent generated skincare imagery as actual client treatment results.
